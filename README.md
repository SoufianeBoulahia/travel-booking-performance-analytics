# Travel API Performance Monitoring

This project analyzes the performance of travel booking APIs across key flows:
- Prebook
- Book
- Valuation

## Objective
- Monitor error rates by provider and agency
- Track API response times
- Detect anomalies in booking, prebook, and valuation flows
- Generate business and optimization insights for account management

## Tools Used
- Python
- Pandas
- Matplotlib
- Google Colab
- CSV Log Data

## KPIs Analyzed
- Total Requests
- Total Errors
- Error Rate (%)
- Average Response Time
- Booking Performance

## Alert System
Automatic detection of providers exceeding error thresholds.
